# Experimental Results

## Voltage Measurement

The prototype was tested for real-time AC voltage measurement.

## Current Measurement

The SCT-013-000 was used for non-invasive current measurement.

## Wireless Communication

Sensor measurements were transmitted from the sensor unit
to the receiver using ESP-NOW.

## Cloud Monitoring

The receiver published measurement data to the MQTT cloud
platform.

## Phantom Load Detection

The system monitored the measured electrical parameters and
identified the configured phantom-load condition.

## Prototype Validation

The prototype was tested using the implemented ESP32 sensor
and receiver units.
