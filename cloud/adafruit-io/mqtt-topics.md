# MQTT Data

The receiver publishes the following measurements:

| Feed               |         Data            |
|--------------------|-------------------------|
| live-voltage       | AC voltage              |
| live-current       | AC current              |
| power              | Power consumption       |
| power-factor       | Power factor            |
| phantom-voltage    | Phantom-load indication |
| energy-consumption | Energy consumption      |
| system-status      | System state            |
| statistics         | System statistics       |
